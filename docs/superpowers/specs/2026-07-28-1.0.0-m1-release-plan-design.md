# Scalus 1.0.0-M1 Release Plan – Design

Date: 2026-07-28
Status: approved

## Context

- Last release: v0.18.2 (2026-06-19). Master carries ~90 commits since, including
  binary-breaking changes (MiMa-verified against 0.18.2: `CardanoBuiltins.->:` removed,
  `Blueprint` arity, `BlockchainReader`/`BlockchainReaderTF`/`EmulatorBase` trait changes,
  `ImmutableEmulator` arity) and behavioral changes (`BigInt./` -> `quotientInteger`,
  custom `Eq` instances rejected on-chain, PV11 default, SIRVersion 6.0).
- The van Rossem hard fork (PV11) was enacted on mainnet 2026-07-18.
- Decision: skip 0.19.0 and release master as **1.0.0-M1**. The existing "0.19.0"
  changelog entry and MiMa filter comments are retitled to 1.0.0-M1.

## Stability promise

- **Stable surface (MiMa-checked from M1 onward):** `scalus-core`, `scalus-cardano-ledger`,
  `scalus-bloxbean-cardano-client-lib`.
- Published disclaimer (README + site): most APIs are stable; some parts will likely have
  breaking changes in 1.x versions, always following a deprecation cycle.
- Not part of the promise: `scalus-testkit` (best effort), `scalus-examples`,
  `scalus-uplc-jit-compiler` (experimental, unpublished), compiler-plugin internals,
  `*.internal` packages.

## Workstream 1 – Cleanup (before M1)

1. Remove all deprecated code (1.0.0 is the break point; every item has a trivial
   replacement and is unused internally):
   - `type`/`val ReprTag` (`compiler/intrinsics/ReprTag.scala`, 0.16.0)
   - `type scalus.ScalusDebug`, `type scalus.CompileDerivations`
     (`scalus/Compiler.scala`, 0.18.1)
   - `def w7l(Long)`, `def w7l(BigInt)` (`serialization/flat/package.scala`, 0.18.2)
   - Keep: `Language.PlutusV4` doc-only deprecation (load-bearing, 85 usages).
2. Remove legacy bloxbean evaluator:
   - Delete `bloxbean/TxEvaluator.scala` (687 lines; only consumer is its own test,
     redundant with `PlutusScriptEvaluatorTest`) and `TxEvaluatorTest.scala`.
   - Keep `bloxbean/Interop.scala` in full (decision 2026-07-28): the
     `getTxInfo*`/`getScriptContext*`/cert/gov/value/interval builders,
     `translateMachineParamsFromCostMdls`, and `getCostModels(CostMdls)` stay even
     though `TxEvaluator` was their only internal consumer – they are public
     CCL-facing API.
   - Keep: `EvaluatorMode.java`, `ScalusTransactionEvaluator`, `ScalusUtxoResolver`,
     `CclUtxoResolver`, `StakeStateResolver`, suppliers.
   - MiMa: needs filters (or lands before the M1 baseline is set, which makes it free).
3. Delete stale markers (audit category E): `utils/Macros.scala` stripTrailing workaround
   comment, `ledger/Entities.scala` dev-placeholder exception comment, stray
   `modpow-bug.scala` at repo root.

## Workstream 2 – Correctness fixes (selected from the TODO/FIXME audit)

Full inventory with dispositions: `docs/internal/PRE_1.0_TODO_AUDIT.md`.

Blocks M1 (wire-format or on-chain semantics; done: S2 optId codec + SIRVersion 6.0):

- **F1 MultiIndexArray**: remove (or hard-gate off the on-chain surface) the
  Scalus-invented builtin with fake flat tag 101 (`DefaultFun.scala`,
  `builtin/Builtins.scala`). Scripts using it fail under real Plutus tooling.
- **Flat buffer sizing**: root-cause the `+ 2` in `ProgramFlatCodec.scala:14`;
  either document with a test or fix.
- **Ord non-override bug**: `prelude/Ord.scala:28,:48` + `builtin/ByteString.scala:120`;
  the `override` does not dispatch in generic functions, giving wrong polymorphic
  comparisons. One fix, three sites.

Milestone phase (M1 if time permits, otherwise M2):

- **Parser/loader validation**: `UplcParser.scala:369` (validate escape sequences),
  `utils/Utils.scala:53` (validate version/builtins when loading UPLC).
- **Ledger quartet**:
  - `WrongNetworkValidator.scala:42` – treat Byron `getNetwork == None` as invalid.
  - `AllWitnessesKeyHashes.scala:28` – implement bootstrap witness key hashes
    (currently `View.empty`, under-counts witness checks).
  - `TransactionStepsProcessor.scala:696` – verify the UnregCert-family
    cert-witness matching against cardano-ledger; fix or remove the marker.
  - `Types.scala:27` – enforce Coin >= 0 in ledger rules.
  - `OutsideForecastValidator.scala:5` – replicate the Haskell forecast-horizon
    failure mode instead of always succeeding.

Deferred post-1.0 (tracked in the report, not milestone work): compiler/plugin
A-items (SIRType case-class contract, SirTypeUplcGenerator `???`, SIRLinker
workaround, Lowering type checks, plugin unchecked assumptions), all B-category
feature gaps, all C/D performance/cleanup notes.

## Workstream 3 – MiMa for the stable surface

1. Enable `MimaPlugin` on `scalusCardanoLedger` (drop `.disablePlugins`), set
   `mimaPreviousArtifacts := Set(organization.value %%% name.value % scalusCompatibleVersion)`.
2. Extend the CI-gated `mima` alias from bloxbean-only to:
   `scalusJVM`, `scalusCardanoLedgerJVM`, `scalus-bloxbean-cardano-client-lib`
   (JS/Native stay covered by the shared-source JVM check; `%%%` config remains for
   opt-in per-platform runs).
3. Baseline policy: after M1 is published, `scalusCompatibleVersion = "1.0.0-M1"` and
   the stale 0.18.0-era filters (Blueprint arity, ScalusDebug/CompileDerivations,
   MissingTypes set, flat-move filters) are deleted. Each milestone re-baselines to the
   previous one; intentional breaks require a reviewed `mimaBinaryIssueFilters` entry
   with a comment.

## Workstream 4 – Release collateral

- CHANGELOG: retitle the pending entry to `1.0.0-M1`, fold in cleanup/fix items.
- Migration guide 0.18 -> 1.0 (site + release notes): `BigInt./` semantics change,
  custom `Eq` instances rejected (use `Eq.derived`/`Eq.structural`), provider trait
  changes (`BlockchainReaderTF.mapF`, `EmulatorBase` tx log), removed deprecations
  and their replacements, PV11 default, script-hash changes on recompile,
  `TxEvaluator` removal (use `ScalusTransactionEvaluator`/`PlutusScriptEvaluator`).
- Stability disclaimer in README and site docs.
- Release: tag `v1.0.0-M1`, sbt-ci-release publishes. Post-release: bump
  `scalusStableVersion`, g8 templates, site version references.

## Out of scope for M1

- `InteropSurfaceTest` implementation (spec:
  `2026-07-11-cross-language-interop-style-guide-design.md`) – proposed M2 item.
- B-category feature gaps (BLS on-chain multiScalarMul lists, mutual recursion in
  simple lowering, borer#764-blocked items, PlutusV4Params) – dispositions in the report.
- scalus-uplc-jit-compiler changes (stays experimental and unpublished).
