final case class ChainConfig

How the Emulator behaves as a chain, spec section 5.

The constructor is private, so Scala 3 makes apply and copy private too: Java and JS cannot use their default parameters, spec [CF-1]. Start from ChainConfig.instant or ChainConfig.manual and change a field with its with method, spec [CF-3].

Value parameters

activeSlotsCoeff

f, the share of slots with a block, which sets the expected blocks of an epoch under Measured, ledger-rules spec [ES-2a], [RW-14]. Above 0.

blockIssuer

the pool each forged block counts for, ledger-rules spec [ES-3]

poolPerformance

how the reward calculation rates the pools, ledger-rules spec [ES-1]

securityParam

k, the deepest rollback the Emulator allows. At least 1.
