def ledgerNames(ex: TransactionException): Seq[String]

The cardano-ledger predicate-failure constructors that ex stands for, at the level that the Imp tests' injectFailure takes, spec [FL-6]: one name per constructor that the fields of ex show, sorted by ledgerOrder. An exception with no ledger counterpart gives its ruleName.

The cardano-ledger predicate-failure constructors that ex stands for, at the level that the Imp tests' injectFailure takes, spec [FL-6]: one name per constructor that the fields of ex show, sorted by ledgerOrder. An exception with no ledger counterpart gives its ruleName.

Unlike ruleName, which names the Scalus rule and stays stable for scalus.cardano.node.SubmitError.rule, these are the names a Haskell ledger test asserts on, for example FeeTooSmallUTxO or CollectErrors.

The names are those of protocol version 11. Below it the ledger raises IncorrectDepositDELEG for DepositIncorrectDELEG and RefundIncorrectDELEG, and PPViewHashesDontMatch for ScriptIntegrityHashMismatch.

Attributes

def ruleName(ex: TransactionException): String

Short, stable name for the rule that raised ex — the exception's own name without the Exception suffix, e.g. "ValueNotConservedUTxO", unless the name is the ledger constructor's, e.g. "VRFKeyHashAlreadyRegistered"; a GovException gives the name of its GovFailure case.

Short, stable name for the rule that raised ex — the exception's own name without the Exception suffix, e.g. "ValueNotConservedUTxO", unless the name is the ledger constructor's, e.g. "VRFKeyHashAlreadyRegistered"; a GovException gives the name of its GovFailure case.

Written out as literals rather than derived from getClass.getSimpleName, which Scala.js minification turns into a meaningless short name, or from productPrefix, which MetadataException does not have. The match has no wildcard on purpose: adding a TransactionException without naming it here makes this match non-exhaustive, and the compiler says so, which is what stops the next rule from silently arriving as an anonymous rejection. (A warning, not an error - this build does not turn warnings into errors.)

Used by scalus.cardano.node.SubmitError.fromException to name rejections that do not map onto one of its classified cases.
