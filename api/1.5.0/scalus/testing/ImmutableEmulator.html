ImmutableEmulator

scalus.testing.ImmutableEmulator
See theImmutableEmulator companion object
final case class ImmutableEmulator

An immutable emulator for Cardano transactions.

Unlike scalus.cardano.node.Emulator, this emulator is fully immutable: every state-changing operation (submit, produceBlock, rollback, setSlot) returns a new ImmutableEmulator instance, leaving the original unchanged.

It wraps the same EmulatorState the mutable emulator runs on, so the chain, the mempool and the presets of scalus.cardano.node.emulator.ChainConfig behave the same way, spec [SF-11]. The validators and mutators stay parameters, spec [SF-12]. Every transition goes through the EmulatorState transitions that revalidate the mempool, spec [DE-3].

This makes it suitable for use in functional state-threading patterns such as the Scenario monad, where branching and backtracking require independent state copies.
