class PlutusV3Params extends PlutusParams

Plutus V3 cost model parameters.

The names of the fields are taken from https://github.com/input-output-hk/plutus/blob/1.63.0.0/plutus-ledger-api/src/PlutusLedgerApi/V3/ParamName.hs and Blockfrost Protocol Parameters JSON uses these names as well in blockfrost-params-epoch-645.json

But what's really important is the order of the fields because that's the order of the parameters in the protocol parameters array.
