def requireVersionCanCarry(program: DeBruijnedProgram): Unit

Rejects a program that declares a version below 1.1.0 but contains constr/case.

Rejects a program that declares a version below 1.1.0 but contains constr/case.

This is the check the Plutus decoder makes ("'constr' is not allowed before version 1.1.0"), applied on both sides of this codec: on encode, so Scalus cannot produce bytes the ledger will reject; on decode, so Scalus does not accept bytes the ledger would not.
