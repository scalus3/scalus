def fromBytes(bytes: Array[Byte], protocolVersion: ProtocolVersion): Address

Parse address from raw bytes, as a node reads one at protocolVersion.

Parse address from raw bytes, as a node reads one at protocolVersion.

The version only changes how a pointer address reads (see Pointer.fromBytes): before version 9 a pointer that does not fit the ledger's widths reads as Pointer(Slot(0), 0, 0), and before version 7 bytes after the pointer are dropped. From version 9 both fail.

def fromBytesLenient(bytes: Array[Byte]): Address

Parse an address a node already holds, such as the address of an output in its UTxO set, as the ledger's decompactAddr reads one.

Parse an address a node already holds, such as the address of an output in its UTxO set, as the ledger's decompactAddr reads one.

A pointer reads as before protocol version 7: one that does not fit the ledger's widths reads as Pointer(Slot(0), 0, 0), and bytes after it are dropped. An output written before version 9 can have such a pointer, so use this for an address that chain data gives, as a provider's UTxO does. An address a user gives is checked with fromBytes instead, as a node checks it in a new transaction.
