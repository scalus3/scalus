final override def encode(a: TypeVar, encoderState: EncoderState): Unit

Writes a into encode.

Writes a into encode.

The buffer does not grow, so it must already have room for bitSize bits. Failing that is a defect in this instance rather than a problem with a: an under-estimating bitSize overruns the buffer with an ArrayIndexOutOfBoundsException, and a negative size is rejected by scalus.serialization.flat.EncoderState with an IllegalArgumentException. Use [[FlatCodec.encodeA*]] to get the sizing right.
