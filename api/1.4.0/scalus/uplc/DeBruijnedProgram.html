case class DeBruijnedProgram

A De Bruijn-indexed program.

A De Bruijn-indexed program is a versioned Term where the variables are indexed using De Bruijn indices. A program must be De Bruijn-indexed before it can be evaluated.

infix def alphaEq(that: DeBruijnedProgram): Boolean

Checks if two programs are equal.

Checks if two programs are equal.

Two programs are equal if their versions are equal and their terms are alpha-equivalent. This means that the names of the variables are not important, only their De Bruijn indices. We use unique negative indices to represent free variables.

Flat-encoded representation of the program.

The flat-encoded representation is a byte array that contains the program in a flat format. This format is used to serialize the program to CBOR. BLS12-381 constants are automatically replaced with uncompress(compressed_bytes) since they have no flat encoding.
