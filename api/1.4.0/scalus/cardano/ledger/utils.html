object TxBalance

The value a transaction consumes and produces.

The value a transaction consumes and produces.

The ledger sums both sides with Haskell's Integer, and so do consumedExact and producedExact, which the value-conservation rule compares. A transaction sets amounts of up to Long.MaxValue in its outputs, deposits and withdrawals, so a Long sum could wrap around and make two different totals look equal. consumed and produced return the same totals as a Value and throw ArithmeticException when one does not fit.
